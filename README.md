A GTA 6 meme for launch week: Lucia and Jason in Vice City spot the make.fun ghost carrying a bag of cash — GTA 6 finally drops, but my AI agent already won on make.fun.

The program (`main.ts`, Node 22) copies the bundled meme image to the graded output as `entry.png`, using only the Node standard library and no network.

Run: `node main.ts` (writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` or `/output`).
